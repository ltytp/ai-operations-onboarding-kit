# 導入準備完了

このDocumentと同じ場所にある2つのFolderだけで導入を開始できます。

```text
導入Kit/
├─ 導入前診断/
├─ 運用保守app/
└─ 導入準備完了.md
```

## 配置

この3項目を、導入対象のGit Repository内の任意の場所へ置きます。Workspace root直下、`tools/onboarding/`、`.ops/setup/`など、深さやFolder名は固定されません。

運用保守側の入口は自分の位置から最も近い`.git`をWorkspace rootとして検出し、そのWorkspace内をMarker fileで探索して診断Folderを見つけます。診断・運用保守の両Folderは相対Path単位で診断対象から除外されます。

別のGit Repositoryや別Mountに分離する場合だけ、`--workspace-root`と`--diagnosis-root`、または対応する環境変数を指定します。

## Agentへ渡すPrompt

```text
Repository内に導入用の2つのFolderと「導入準備完了.md」を配置しました。
最初に「導入準備完了.md」を読み、2つのFolderのAGENTS.md、START_HERE.md、README.mdを確認してください。

運用保守Folderのworkspace_onboard.py doctorを実行して、Git Workspace、診断Folder、運用保守Folder、Targetを確認してください。
問題がなければstartで読取専用診断を実行してください。導入Toolの2 Folderは診断対象から除外してください。

診断Report、Open Questions、Golden Work Item候補を説明してください。承認者名、Review evidence、Security判断は推測せず、必要なGateで私に確認してください。
ONBOARDING_APPROVEDになるまではImportしないでください。
承認後はSource fingerprintを再照合し、Bootstrap Importを実行して、System ID、Scan ID、生成されたGraph seed、Import receiptを報告してください。
```

## Agentが最初に実行するCommand

運用保守Folderを見つけた場所から次を実行します。

```bash
python3 ./運用保守app/workspace_onboard.py doctor
python3 ./運用保守app/workspace_onboard.py start
```

FolderがNested配置なら、Agentは実際の相対Pathへ読み替えます。利用者が絶対Pathを記述する必要はありません。

## 自動停止する条件

- `.git`がなくTarget scopeを確定できない
- 診断Folderが見つからない、または複数見つかる
- 診断・運用保守Folder自体がTargetに指定されている
- Package Schema / Checksumが一致しない
- Golden Work Itemが未確定
- Sign-offが`ONBOARDING_APPROVED`ではない
- 診断後にSource fingerprintが変化した
- 同じScan IDが既にImportされている

停止した場合、AgentはGuardを無効化せず、理由と必要な利用者判断を報告します。

## 任意配置のFallback

2つのFolderが同じGit Workspace内にない場合:

```bash
python3 /path/to/operations/workspace_onboard.py doctor \
  --workspace-root /path/to/target-repository \
  --diagnosis-root /path/to/diagnosis
```

環境変数でも指定できます。

```bash
export ONBOARDING_WORKSPACE_ROOT=/path/to/target-repository
export ONBOARDING_DIAGNOSIS_ROOT=/path/to/diagnosis
export ONBOARDING_OPERATIONS_ROOT=/path/to/operations
```

## 導入後

成果物は運用保守Folder内の次の場所へ作成されます。

```text
systems/<system-id>/
├─ config/
├─ onboarding/packages/<scan-id>/
├─ inventory/
├─ decisions/
└─ graph-seeds/

import-receipts/<scan-id>.json
```

対象Repositoryの原本はCopy・移動しません。
